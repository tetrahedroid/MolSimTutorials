# MolSimTutorials

「学生用資料 分子シミュレーション研究の手引き」の書換えを試みます。

* セクションごとにファイルを分けます。

## VSCodeで読む方法

1. VScodeに以下の拡張機能を追加する。
   * Markdown Preview Enhancer (CSSのカスタマイズ)
   * Markdown footnotes (footnotesの利用)
2. VSCodeでMolSimTutorialsフォルダーを開く。(TheoChemや学生用資料フォルダーでも中身を見られますが、設定ファイルの所在を見失うようで、プレビューのレイアウトがうまくできませんでした)
3. 拡張子`.md`のファイルを開いたら、`Command-K v`を押して、MarkDownプレビューを表示する。(もしかしたらこれにも拡張機能が要るかも)
4. combined.mdは全ページをつなげたものです。目次から内容をさがすのに便利です。
